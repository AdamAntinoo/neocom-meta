# Agent templates

The user supplies examples of commit messages, branch names, and pull request text over time. When an example arrives, store it in the matching file in this folder and follow it on the next action. Do not keep a competing format once an example is recorded.

| File | Used for |
| --- | --- |
| `branch-names.md` | Feature branches |
| `commit-messages.md` | Commit subjects and bodies |
| `pull-requests.md` | Pull request title and body |

Until a file says an example has been recorded, use the fallback written in that file.
