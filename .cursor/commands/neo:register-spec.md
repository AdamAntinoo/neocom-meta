Run **Register Spec** for the `/neocom-meta` agent.

Command: `/neo:register-spec`

Follow `.cursor/skills/register-requirements/SKILL.md` in `neocom-meta`.

Review every new requirement under `05.REQUIREMENTS-DECOMPOSITION/`, then process it: place it in the file for its system and feature, and register it in OpenSpec. Do not implement product features.
