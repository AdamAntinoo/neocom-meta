Run **Register Spec**. The command code is `/neo:register-spec`.

Follow `.cursor/skills/register-requirements/SKILL.md` in `neocom-meta`. Processing steps are in `.cursor/skills/spec-registration/SKILL.md`.

Process L1 and L2 under `05.REQUIREMENTS-DECOMPOSITION/`, including every `UNREGISTERED REQUIREMENTS` section. Place each new note in the file for its system and feature, then register an OpenSpec change `<system>-<feature>` with the spec at `specs/<system>/<feature>/spec.md`. Do not implement product features.
