## SDE: Static Data Export

SDE data comes from EVE’s **Static Data** service: [Static Data — EVE Developer Documentation](https://developers.eveonline.com/docs/services/static-data/).

The Static Data Export (SDE) is a **downloadable** packaged dataset (JSON Lines and YAML variants; latest build and zip URLs are documented on that page, including short-hand latest downloads). It holds static game universe and related data that changes with game updates, not live authenticated ESI traffic.

This epic SHALL treat the SDE as a **database element** that is:

1. **Downloaded** from the official Static Data distribution (Tranquility SDE builds).
2. **Installed** into the programme’s runtime environment so it is **available to the back server**.
3. Used for **local access** to universe and other static information, **replacing many ESI API calls** that would otherwise hit ESI for the same static facts.

The back server is the consumer that owns install location, load/query of the installed SDE, and serving or adapting that data to domain features (aligned with EPIC-004 published models where applicable). Front and other clients do not download or install the SDE themselves unless a later requirement explicitly says so.

## Service model: JSONL → database

The **service model** for this data is the SDE delivered as **JSON Lines (JSONL)** files (primary format for large datasets per the Static Data docs; YAML may exist but is not the preferred import path for volume).

JSONL files are the **import source**, not the long-term query store. The programme SHALL **import** those JSONL files into a **better database solution** (a proper database chosen for query, indexing, and backend access) so that **all** of this static universe and related SDE data is **available to the backend**.

| Stage | Expectation |
| --- | --- |
| Download | Obtain the SDE package (JSONL variant) from the download endpoint below |
| Import | Load JSONL files into the chosen database (schema and tooling under this epic) |
| Serve | Backend reads from that database for local access; it does not rely on raw JSONL files at request time |

### Download endpoint (JSONL zip)

This URL is the **download endpoint** for the zip that contains **all JSON Lines data** used as the contents to import into the database:

https://developers.eveonline.com/static-data/eve-online-static-data-latest-jsonl.zip

(Documented under [Static Data — Automation](https://developers.eveonline.com/docs/services/static-data/) as the short-hand latest JSON Lines package; it redirects to the current Tranquility build zip.)

The programme SHALL use that endpoint (or the equivalent build-numbered URL resolved from latest) to obtain the full JSONL dataset before import. The backend SHALL treat the imported database as the operational source of SDE-backed data once import has completed successfully.
