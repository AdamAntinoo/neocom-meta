# L0 archive

Deleted executive cards. A card is moved here when its epic reference is set to the `[deleted]` state (or its `INDEX.md` row state becomes `deleted`).

- Each file below groups the deleted cards by source list (`FRONT`, `BACK`, `DATAMANAGEMENT`, `INFRA`, `TESTING`).
- A card in this directory is removed from `sources/L0/executive/<LIST>.md` and is **unavailable to every epic**.
- Never re-add an archived card to an epic without first moving it back to the executive list and resetting its `INDEX.md` state.
