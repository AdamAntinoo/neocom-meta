Topic: corporation panel right of pilot; ESI public corporation data via NeoCom back; `v1-corporation-render` HEADER Appearance; alliance name + home location path enrichment.

## Corporation panel (`v1-corporation-render`)

| ID | Status | Requirement |
| --- | --- | --- |
| UI-CORP-001 | registered | Corporation information panel SHALL sit to the **right** of the pilot panel on the Pilot & corporation row (complements the pilot; not inside `app-page-header`) |
| UI-CORP-002 | registered | **First implementation task:** obtain **public corporation data** for the selected pilot’s `corporation_id` from ESI **`GET /corporations/{corporation_id}/`** (via the NeoCom public corporation back endpoint / provider — front does not call ESI directly) |
| UI-CORP-003 | registered | Corporation id SHALL come from the **selected Pilot** (`getCorporationId()` / PilotV2 corporation link) |
| UI-CORP-004 | registered | The ESI public corporation field set consumed for this render is at least **`name`**, **`ticker`**, **`member_count`**, **`tax_rate`**, **`ceo_id`**, **`home_station_id`**, and **`alliance_id`** when present; the back MAY retain the full public payload listed in this section |
| UI-CORP-005 | registered | `model-strip-page` SHALL host a **`v1-corporation-render`** specimen (render name + style reference); Appearance PNG is captured from that specimen |
| UI-CORP-006 | registered | New work SHALL paint corporation content with versioned **`v1-corporation-render`** (UI-VER-*); legacy `corporation-public-data-panel` / unversioned `corporation-render` are transitional only |
| UI-CORP-007 | registered | Panel chrome SHALL use **`neocom-panel panel-orange`** |
| UI-CORP-008 | registered | Corporation HEADER SHALL show **logo**, **name**, **ticker in brackets beside the name** (`Name [TICKER]`), **member_count**, and **tax_rate** (percent from ESI 0…1) |
| UI-CORP-009 | registered | When **`alliance_id`** is present, the render SHALL show the **alliance name** from ESI **Get alliance information** (`GET /alliances/{alliance_id}/`); when absent, omit the alliance line |
| UI-CORP-010 | registered | Corporation logo URL SHALL use the EVE Image Server `corporations/{corporationId}/logo` pattern (**Media from the EVE Image Server** / EPIC-004); missing id → documented default logo id `1` |
| UI-CORP-011 | registered | When **`home_station_id`** is present, the render SHALL show the home location as **`name >> system >> constellation >> region`** from the space-location / EveLocation chain for that id; when absent, omit the home line |
| UI-CORP-012 | registered | Front SHALL NOT call ESI for corporation, alliance, or location enrichment — NeoCom back / providers supply the enriched node (alliance name + home path) to the render |
| UI-CORP-013 | registered | Dashboard panel host MAY still show a **CEO** column from `ceo_id` (pilot HEADER); the long-term corporation **card** is `v1-corporation-render` (alliance name on the card, not a separate alliance render column) |
