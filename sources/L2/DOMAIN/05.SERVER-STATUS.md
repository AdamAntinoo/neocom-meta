| DOM-SRV-001 | registered | **ServerStatusV1** SHALL be the published domain model for EVE Online server information in the application header (`jsonClass = "ServerStatusV1"`). Infinity legacy class `ServerStatus.domain.ts` (unversioned name). Legacy `server-info-panel` superseded by provider → **`v1-server-status-render`**. ESI server status shape is **internal**; ServerStatusV1 may add NeoCom fields not in ESI alone. |
| DOM-SRV-002 | registered | ServerStatusV1 SHALL expose fields: `server` (`getServerName()`), `players` (`getPlayersCount()`, default `0`), `start_time` (`getStartTime()`), `backendVersion`, `SDEVersion`, `startAgo` (`getStartedAgo`), `nextDowntime`. |
| DOM-SRV-003 | registered | Header provider obtains ServerStatusV1; `v1-server-status-render` SHALL show at least server name, ONLINE/OFFLINE (ONLINE when status instance present), capsuleer count, backend version, SDE version, next downtime; loading while request in flight. ONLINE/OFFLINE is UI derivation in infinity (`getServerStatus()`), not a stored field. Appearance: `v1-server-status-render` (`media/v1-server-status-render.png`). |
