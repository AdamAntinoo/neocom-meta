Source: `L2/08.EPIC-LOCATIONS.md` (identity, SpaceLocation node, Region, Constellation, Solar system, Station, Structure). Lookup endpoint LOC-010 is `back-spacelocations`.

| ID | Status | Requirement |
| --- | --- | --- |
| LOC-001 | registered | A published location SHALL name its kind. Infinity does this with `locationType` (`LocationIdentifierType`) and uses the most specific id as `locationId`. |
| LOC-002 | registered | A deeper location SHALL carry its ancestor place (region, and constellation or system when those levels exist) so a render can show the chain without a second lookup. |
| DOM-LOC-001 | registered | A location is one node in a chain. The most specific level supplied sets `locationType` and `locationId`. Ancestor levels are copied onto the same object. `locationType` values: `REGION`, `CONSTELLATION`, `SOLAR_SYSTEM`, `STATION`, `STRUCTURE`, with ancestor fields as in the EPIC-008 identity table. |
| DOM-LOC-002 | registered | **SpaceLocation** lookup node SHALL expose `locationType` and `locationId` (id of the most specific level). Domain type in the library: `org.dimensinfin.eveonline.neocom.domain.space.SpaceLocation` / `SpaceLocationImplementation`. |
| LOC-020 | registered | A region location SHALL expose `regionId` and `regionName`, and `locationId` SHALL be the region id (`locationType = REGION`). Fixture region **1000043** Domain. |
| LOC-030 | registered | A constellation location SHALL expose constellation id and name plus the parent region (`locationType = CONSTELLATION`). Fixture constellation **20000322** Throne Worlds. |
| LOC-040 | registered | A solar-system location SHALL expose system id, name, `securityClass`, and `securityStatus`, plus constellation and region (`locationType = SOLAR_SYSTEM`). Serializer names `solarSystemId` / `solarSystemName`. Fixture system **30002187** Amarr. |
| LOC-050 | registered | A station location SHALL expose station id and name plus the system, constellation, and region it sits in (`locationType = STATION`). Fixture station **60008494**. |
| LOC-051 | registered | A shipping yard and a corporation home station SHALL resolve to a **Station**, not to a bare id. |
| LOC-060 | registered | A structure location SHALL expose structure id, name, type id, owner id, and corporation id and name, plus the system chain (`locationType = STRUCTURE`). |
