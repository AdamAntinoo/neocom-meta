| UI-MED-001 | registered | Portraits, corporation/alliance logos, and type icons SHALL be loaded by the **client** directly from the EVE Image Server |

| UI-MED-007 | registered | When a character, corporation, or alliance id is missing, the URL SHALL use id **`1`** |
