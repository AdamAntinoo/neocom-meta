# Universe

Status: recorded. OpenSpec change: `front-universe`.

Universe is ESI data that can be downloaded without authentication. The first operations complete the Pilot model: ancestries, bloodlines, factions, graphics, groups, categories, and the group and category id lookups. The front end reads that data through an adapter and may cache it on the client (UNIV-003).
