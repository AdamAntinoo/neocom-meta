# Pilot panel

Status: recorded. OpenSpec change: `front-pilot-panel`.

A panel renders the Pilot model from an EVE character identifier. It can show public data and private data, and can hide the private data when no credential is available. Listings use a partial render and mark the active pilot with a greenish background.
