# neocom-domain

Status: recorded. OpenSpec change: `domain-module`.

https://github.com/AdamAntinoo/neocom-domain.git is a submodule and a Node TypeScript package for business-domain types. Front and back depend on it from npm.

Business objects in that package are versioned. A new shape is a new type, and features that use an older model keep that older type. See `ARCHITECTURE/MODELS.md`.

Source: `05.REQUIREMENTS-DECOMPOSITION/L2/DOMAIN/01.NEOCOM-DOMAIN.md`.
