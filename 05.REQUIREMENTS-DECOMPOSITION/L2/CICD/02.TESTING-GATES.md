| ID | Status | Requirement |
| --- | --- | --- |
| GATE-001 | registered | CI/CD unit-testing and acceptance-testing tasks **MAY run in parallel**. |
| GATE-002 | registered | Both unit testing and acceptance testing SHALL complete successfully before the **SonarCloud analysis / quality-gate** step. |
