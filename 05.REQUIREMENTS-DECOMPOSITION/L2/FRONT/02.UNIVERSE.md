# Universe

System: `front`. Feature: `universe`.
OpenSpec change: `front-universe` → `specs/front/universe/spec.md`.

Universe is ESI data that can be downloaded without authentication. The endpoints below are the initial set required to complete the Pilot data model.

| ID | Status | Requirement |
| --- | --- | --- |
| UNIV-001 | registered | Many ESI datasets can be downloaded with no authentication, and together they conform the Universe |
| UNIV-002 | registered | Initial unauthenticated ESI endpoints required to complete the Pilot data model are GetUniverseAncestries, GetUniverseBloodlines, GetUniverseFactions, GetUniverseGraphics, GetUniverseGroups, GetUniverseGroupsGroupId, GetUniverseCategories, and GetUniverseCategoriesCategoryId (https://developers.eveonline.com/api-explorer) |
| UNIV-003 | registered | ESI universe data is accessed directly from the front end, because it does not require authentication, using an adapter. Retrieved data can be cached on the client because it usually does not change over time or across pilots |
