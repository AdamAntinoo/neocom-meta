# Pilot

System: `front`. Feature: `pilot`.
OpenSpec change: `front-pilot` → `specs/front/pilot/spec.md`.

A pilot is the Eve Online user's interaction with the game environment. Inside this concept the ESI entity is named Character.

| ID | Status | Requirement |
| --- | --- | --- |
| PILOT-001 | registered | A pilot is the concept of the Eve Online user interaction with the game environment |
| PILOT-002 | registered | A pilot belongs to a game credential, and a credential can have up to 3 pilots |
| PILOT-003 | registered | Pilot public contents come from ESI **Get character's public information** (`GetCharactersDetail`): `GET https://esi.evetech.net/characters/{character_id}` — https://developers.eveonline.com/api-explorer#/operations/GetCharactersDetail |
| PILOT-004 | registered | Inside the Pilot concept the game entity is named Character |
