# front/character-selection Specification

## Purpose

Character selection UI before Dashboard. Source: UI-CHAR-002 in .

## ADDED Requirements

### Requirement: Character selection before Dashboard

Character selection UI (page or panel) SHALL be part of the auth experience before Dashboard; its visual template SHALL be aligned with EPIC-006 listing/render patterns and PilotV2 (EPIC-004) (UI-CHAR-002).

#### Scenario: Selection precedes landing

- **WHEN** the user has authenticated but has not completed character selection
- **THEN** character selection UI is shown before Dashboard
