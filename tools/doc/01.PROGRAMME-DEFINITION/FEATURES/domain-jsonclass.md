# Feature — domain jsonClass interchange

| Field | Value |
| --- | --- |
| OpenSpec | `domain-jsonclass` |
| Status | registered |
| Owners | `neocom-back`, `neocom-front`, `neocom-domain` |
| L2 IDs | DOM-JSONCLASS-001 … DOM-JSONCLASS-003 |
| Source |  (EPIC-004 Section 22) |

## Intent

Published domain models on the wire carry `jsonClass` so the front can resolve the correct render without guessing from the URL. Values match `neocom-domain` / EPIC-004 programme type names.
