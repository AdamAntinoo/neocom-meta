# Angular structure

Status: registered. OpenSpec change: `front-angular-structure`.

Page vs panel vs section module (`loadChildren` / `forChild`); shell pages under `app/pages`; core-only panels under `app/panels`; shared header panels under `modules/header`; industry and manufacture section modules in scope; non-section support modules without root routes; placement rules for new screens.

Requirement ids: STRUCT-001 … STRUCT-007. Source: L1 (EPIC-002).
